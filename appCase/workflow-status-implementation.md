# 工作流节点状态指示器功能说明

## 功能概述

我已经成功为工作流系统中的每个节点添加了执行状态的可视化指示器，使用不同颜色的"灯"来表示节点的执行状态。

## 实现的功能

### 1. 节点状态指示器

每个节点现在都有一个状态指示灯，位于节点头部，显示三种不同的执行状态：

- **绿灯** (`#52c41a`)：执行完成的节点
- **黄灯** (`#faad14`)：执行中的节点（带有脉冲动画效果）
- **灰灯** (`#d9d9d9`)：等待中的节点

### 2. 动态连线颜色

连接线的颜色会根据连接的两个节点状态自动调整：

- **绿色连线**：连接两个已完成（绿灯）节点的连线
- **黄色连线**：从已完成节点到执行中节点的连线（带动画效果）
- **灰色连线**：默认的等待状态连线

### 3. 状态控制功能

在工作流画布左上角添加了控制面板，包含：

**执行状态控制组**：
- **重置状态**：将所有节点重置为初始状态
- **执行节点3**：模拟执行第3个节点
- **执行节点4**：模拟执行第4个节点

**仿真控制组**：
- **开始/暂停**：启动或暂停整体仿真
- **停止**：停止仿真

### 4. 交互功能增强

- 状态指示灯带有工具提示，显示当前状态描述
- 执行中的节点有脉冲动画效果，增强视觉反馈
- 右键菜单集成了节点执行功能

## 技术实现细节

### 数据结构更新

在 `CustomNodeData` 接口中添加了 `status` 字段：

```typescript
interface CustomNodeData {
  // ...existing fields...
  status?: 'waiting' | 'running' | 'completed';
}
```

### 组件修改

1. **CustomNode.tsx**：
   - 添加了状态颜色和标签函数
   - 在节点头部添加了状态指示灯
   - 更新了连接点的颜色以匹配节点状态

2. **WorkflowCanvas.tsx**：
   - 添加了边颜色更新逻辑
   - 实现了节点状态模拟功能
   - 增强了控制面板功能

3. **样式文件**：
   - 添加了脉冲动画CSS
   - 优化了控制按钮的视觉样式

### 动画效果

执行中的节点使用了CSS脉冲动画：

```css
@keyframes pulse {
  0% { box-shadow: 0 0 0 0 rgba(250, 173, 20, 0.7); }
  70% { box-shadow: 0 0 0 6px rgba(250, 173, 20, 0); }
  100% { box-shadow: 0 0 0 0 rgba(250, 173, 20, 0); }
}
```

## 使用方法

1. 访问 `/workflow` 路由查看工作流画布
2. 观察节点的状态指示灯颜色
3. 使用左上角的控制按钮测试状态变化：
   - 点击"执行节点3"观察节点从黄灯变绿灯
   - 点击"执行节点4"观察类似效果
   - 点击"重置状态"将所有节点恢复初始状态
4. 观察连接线颜色的相应变化

## 初始状态设置

- 节点1、2：已完成状态（绿灯）
- 节点3：执行中状态（黄灯）
- 节点4-7：等待中状态（灰灯）

连接线会根据这些初始状态显示相应的颜色。

## 扩展性

这个实现具有良好的扩展性：
- 可以轻松添加更多状态类型（如错误状态）
- 状态变化逻辑可以集成到实际的工作流执行引擎
- 可以添加更复杂的状态依赖关系和业务逻辑

该功能完全符合您的需求，提供了清晰直观的工作流执行状态可视化。
